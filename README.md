# Supermarkt-Dashboard

Dashboard Preview

The Overview page presents a comprehensive summary of the supermarket's sales performance through interactive KPI cards and visualizations. It includes key metrics such as Total Revenue, Total Quantity, Total Gross Income, and Average Rating, along with charts showing revenue by branch, product line, payment method, and month. Interactive slicers allow users to filter the data and explore insights dynamically.

The Details page provides a deeper analysis of the sales data by focusing on different business dimensions. It includes visualizations for revenue by city, customer type, gender, and product line, helping users compare performance across locations and customer segments. The dashboard is fully interactive, enabling efficient data exploration and supporting data-driven decision-making.
